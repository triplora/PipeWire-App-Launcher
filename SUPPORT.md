# Support

PipeWire App Launcher is an alpha-stage community project maintained on a
best-effort basis.

## Before requesting help

1. Read the [README](README.md), including the Ubuntu 24.04 host requirements.
2. Confirm that the newest release is being used.
3. Search existing [issues](https://github.com/triplora/PipeWire-App-Launcher/issues).
4. Remove credentials, private audio-project data, usernames, home-directory
   paths, and other personal information from logs.

## Where to ask

- Reproducible defects: use the
  [bug report form](https://github.com/triplora/PipeWire-App-Launcher/issues/new?template=bug_report.yml).
- Feature proposals: use the
  [feature request form](https://github.com/triplora/PipeWire-App-Launcher/issues/new?template=feature_request.yml).
- Usage questions that are not reproducible defects may be opened as a feature
  request only when they identify a concrete documentation or usability gap.

Please do not use Issues for general Linux, PipeWire, JACK, Qt, or third-party
application support.

## Security and conduct

Report vulnerabilities through the private process in
[SECURITY.md](SECURITY.md). Never disclose exploitable details publicly.

Report conduct concerns according to
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), without publishing sensitive details
in an Issue.

There is no guaranteed response time or compatibility commitment while the
project remains in alpha.
